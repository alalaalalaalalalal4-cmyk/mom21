# Site de Aniversário da Mamãe ❤️



## Como usar localmente
1. Basta abrir o arquivo `index.html` em qualquer navegador (Chrome, Edge, Firefox, etc).

## Como hospedar no GitHub Pages (Grátis)
1. Crie um novo repositório no seu GitHub.
2. Faça upload de todos os arquivos (`index.html`, `style.css`, `script.js` e a pasta `assets`).
3. Vá em **Settings** -> **Pages**.
4. Em **Branch**, selecione `main` (ou `master`) e clique em **Save**.
5. Aguarde alguns minutos e o GitHub fornecerá um link (ex: `https://seu-usuario.github.io/nome-do-repo/`).

## Como personalizar
- **Fotos**: Substitua as imagens na pasta `assets` ou atualize os links no `index.html`.
- **Mensagem**: Edite o texto dentro da seção `<section class="message-section">` no `index.html`.
- **Música**: Adicione um arquivo chamado `music.mp3` na pasta `assets`.
- **Surpresa**: Clique no título "Parabéns, Mãe!" para soltar confetes!
